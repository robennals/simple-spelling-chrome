# Fully phonetic mode

**Summary.** In this mode every sound has exactly one spelling. Where British
and American English use different vowels in a word, the spelling keeps them
apart (*bath → bahth*, not *bath* or *baath*), so each reader can apply their
own accent. Consonants are always written in full: *r* and *t* never drop.

> Iy thawt wee shood goh owt taniyt, but miy frend sed shee woz tuu tiyerd tuu leev tha hows. Tha kaar iz ohver thair, neer tha dor, for her faather. Look, a good book! Kant yuu ahsk abowt tha nyuu myuuzik?

The table is built by
[tools/phonetic_mode.py](../tools/phonetic_mode.py). For each word it lines
up the American (CMUdict) and British (ipa-dict) pronunciations sound by
sound. Consonants come from the American one, plus the British "y" in *new*.
Each vowel is spelled from its pair of American and British vowels, which
places it in one of the standard *lexical sets* (the *bath* words, the *lot*
words, and so on). The examples below are generated by the same code.

## Consonants

| Sound | Spelling | Examples |
|---|---|---|
| k | **k** | cat → kat, quick → kwik |
| ks | **ks** | box → boks |
| z | **z** | is → iz, please → pleez |
| f | **f** | phone → fohn, laugh → lahf |
| j | **j** | judge → juj, general → jeneral |
| th (thin, this) | **th** | think → thingk, this → this |
| zh | **zh** | measure → mezher, vision → vizhan |
| w | **w** | when → wen, what → wot |

Other consonants are their usual single letter, never doubled. *ng* is
written as it sounds, so *think* → *thingk*.

## Choices made

- **The *bath* words** (*bath, ask, can't*): *ah*. British says "ah",
  American says the *a* of *cat*.
- **The *cloth* words** (*off, dog, long*) share *o* with *lot*, although
  some American accents give them the *thought* vowel.
- **Both *th* sounds** (*thin*, *this*) are written *th*, as in normal
  spelling. This is the one place a letter pair stands for two sounds.
- **Unstressed "uh"** is *a* (*abowt, tha*).
- **Weak forms** (*to*, *the*, *a*) are written in their full form, so each
  word has one spelling.
- **Contractions** use the base word's British pronunciation plus the ending
  (*aren't* → *aarant*, *what's* → *wots*). *can't* is *kant*, because the
  British dictionary has *can* (*kan*) but not the *kahnt* of *can't*.
- **Abbreviations are left alone** (*st, mr, dr, fbi, etc*): the dictionary
  lists them under their spoken form.

## Which words it covers

- **Every real word in the pronunciation dictionary**: words in CMUdict that
  are also in the British dictionary or the system word list. This leaves out
  most of CMUdict's names. Also the 50,000 most common words in the
  frequency list, and common contractions.
- **British spellings** through their American form for the pronunciation
  (*offence* → *afens*, *colour* → *kuler*).
- **Word forms built while reading.** A word missing from the table that's
  built from one in it is respelled from that word plus the ending, by sound:
  *exhales* → *ekshaylz*, *exhaled* → *ekshayld*. Words known to stay the same
  are listed separately so they're never rebuilt (*need* is not *nee* + *d*).

## Regenerating

```bash
python3 tools/phonetic_mode.py cmudict.dict en_50k.txt en_UK.txt --json extension/phonetic.json
# uses /usr/share/dict/words as the real-word list; override with --wordlist
```
