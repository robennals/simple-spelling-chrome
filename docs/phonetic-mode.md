# Fully phonetic mode

**Summary.** In this mode every sound has exactly one spelling. Where British
and American English use different vowels in a word, the spelling keeps them
apart (*bath → bahth*, not *bath* or *baath*), so each reader can apply their
own accent. Consonants are always written in full: *r* and *t* never drop.

> Iy thawt wee shood goh owt taniyt, but miy frend sed shee woz tuu tiyerd tuu leev dha hows. Dha kaar iz ohver dhair, neer dha dor, for her faadher. Look, a good book! Kant yuu ahsk abowt dha nyuu myuuzik?

The table is built by
[tools/phonetic_mode.py](../tools/phonetic_mode.py). For each word it lines
up the American (CMUdict) and British (ipa-dict) pronunciations sound by
sound. Consonants come from the American one, plus the British "y" in *new*.
Each vowel is spelled from its pair of American and British vowels, which
places it in one of the standard *lexical sets* (the *bath* words, the *lot*
words, and so on). The examples below are generated by the same code.

## Consonants

| Sound | Spelling | Examples |
|---|---|---|
| k | **k** | cat → kat, quick → kwik |
| ks | **ks** | box → boks |
| z | **z** | is → iz, please → pleez |
| f | **f** | phone → fohn, laugh → lahf |
| j | **j** | judge → juj, general → jeneral |
| th (thin) | **th** | thin → thin, think → thingk |
| th (this) | **dh** | this → dhis, the → dha |
| zh | **zh** | measure → mezher, vision → vizhan |
| w | **w** | when → wen, what → wot |

Other consonants are their usual single letter, never doubled. *ng* is
written as it sounds, so *think* → *thingk*.

## Choices made

- **The *bath* words** (*bath, ask, can't*): *ah*. British says "ah",
  American says the *a* of *cat*.
- **The *cloth* words** (*off, dog, long*) share *o* with *lot*, although
  some American accents give them the *thought* vowel.
- **The two *th* sounds** are *th* (*thin*) and *dh* (*this, the*).
- **Unstressed "uh"** is *a* (*abowt, dha*).
- **Weak forms** (*to*, *the*, *a*) are written in their full form, so each
  word has one spelling.
- **Contractions** use the American pronunciation, because the British
  dictionary doesn't list them (*can't* → *kant*).

## Regenerating

```bash
python3 tools/phonetic_mode.py cmudict.dict en_50k.txt en_UK.txt --json extension/phonetic.json
```
